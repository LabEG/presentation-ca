🚀 .Net Core 2 → .Net Core 3

⚠️ Проблема: EF Core изменил поведение LINQ запросов
❌ Было (EF Core 2) 

context.Namings
	.Where(n => n.IsActive)
	.Where(call_csharp_function)
	.ToList();
Работало без проблем
✅ Стало (EF Core 3+) 

context.Namings
	.Where(n => n.IsActive)
	.ToList()  // ← Принудительное выполнение
	.Where(call_csharp_function)
	.ToList();
Требуется .ToList() перед C# функциями
💡 EF Core 3.0+ не может транслировать произвольные C# методы в SQL

.Net 5 → .Net 6

Npgsql 6.0 ⚠️ Breaking Change
🕐

Строгая типизация DateTime

timestamp → DateTime с Kind=Unspecified
timestamptz → DateTime с Kind=Utc или DateTimeOffset
⚡

Влияние изменений

Ранее Npgsql не проверял Kind строго, что могло приводить к ошибкам интерпретации времени (UTC время ошибочно считалось локальным)

🐰 RabbitMQ Client ⚡ Async/Await
🔄

Масштабная рефакторизация

В C# библиотеке RabbitMQ пришлось переделать все методы с синхронных на асинхронные

Трансформация методов

Синхронные методы
channel.BasicPublish(...)
channel.BasicConsume(...)
channel.QueueDeclare(...)
connection.CreateModel()
→ async/await
Асинхронные методы
await channel.BasicPublishAsync(...)
await channel.BasicConsumeAsync(...)
await channel.QueueDeclareAsync(...)
await connection.CreateModelAsync()
